# Efficient Neural Architecture Search (ENAS) Based Low-Frequency Attack Detection in Software Defined Networks

## Project Overview

This project focuses on detecting Low-Frequency Attacks (LFAs) in Software Defined Networks (SDNs) using machine learning and deep learning techniques.

The project explores efficient neural architecture search and network traffic analysis approaches to distinguish normal network traffic from malicious traffic.

## Objectives

- Understand Software Defined Networking architecture and its security challenges.
- Study different types of Low-Frequency Attacks.
- Analyze and preprocess network traffic datasets.
- Explore suitable machine learning and deep learning models.
- Develop an approach for detecting normal and malicious network traffic.
- Evaluate model performance using standard classification metrics.
